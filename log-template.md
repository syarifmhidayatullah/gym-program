# Template Log untuk Review

Kirim ke chat project setiap akhir minggu, atau di akhir minggu ke-4 untuk menghitung siklus berikutnya. Screenshot dari aplikasi tracker juga boleh, asal rasa per set lift utama ditulis.

Rasa per set: **enteng** · **berat tapi aman** · **mentok** (atau "gagal di rep ke-X").

```
(aksesori lain cukup beban × rep)

...

...

...

Sabtu – Full Body Ringan
Pause squat 52,5 kg 3×3, paused bench 50 kg 3×3, deadlift 70 kg 5×2 — semua enteng / ada yang melambat

Catatan
- Tidur: rata-rata ... jam, malam terburuk ...
- Energi / pemulihan: ...
- Nyeri atau tidak nyaman: (sendi mana, saat gerakan apa)
- Sesi yang terlewat atau diganti: ...
- Tambahan malam (pull-up / push-up / boxing): ...
```
